# DeepFace KYC Service

A Docker-based DeepFace biometric verification microservice used in the DeepKYC platform.

## Features

- Face verification
- Identity matching
- Biometric authentication
- DeepFace-powered facial analysis

## Deployment

This service is deployed as a Hugging Face Docker Space and automatically updated through GitHub Actions.
